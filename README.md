# VEX V5 Classroom Programmer

A student-friendly VEX V5 programming environment for practicing with Blocks or Python and testing code in an interactive robot simulator.

## Features

- Separate Blocks and Python practice workspaces
- VEXcode-style Python command drawers and syntax highlighting
- Configurable V5 Smart Ports and 3-Wire ports
- One-click PLTW classroom testbed setup
- Side-by-side programming workspace and robot simulator
- Interactive bumper, limit, light, line, and potentiometer sensors
- Motor, drivetrain, LED, and Brain screen simulation
- Multiple playgrounds with walls, movable crates, goals, and breakable structures
- Friendly code and indentation messages for students
- Run, pause, step, stop, speed, robot reset, and floor reset controls
- Browser autosave and project-file save/open
